# 2.5D 與三職業動畫方向草案

Owner 最新方向：參考《皇室戰爭》，現在就開始動畫設計。下面是 TacticalGo 的設計提案；微動畫比較已可操作，完整三職業分鏡仍是草案，尚未製作 sprite 或接入遊戲。

## 視覺方向

參考 [Supercell 官方《皇室戰爭》頁面](https://supercell.com/en/games/clashroyale/) 的角色與對戰畫面：用較大的形體、清楚主道具、集中亮部和落地投影，增加英雄份量感。官方 [Media Center](https://supercell.com/en/media-center/) 提供演示影片，可供後續節奏對照。以下時間由本輪提出，沒有宣稱是官方動畫數值或已逐幀量測。

| 項目 | TacticalGo 方向 |
| --- | --- |
| 世界觀 | 可愛奇幻 RPG＋實體桌遊；維持現有角色身分與較明亮膚色 |
| 形體 | 大盾、帽／水晶、兜帽／單短刃做成有厚度的主體，減少小裝飾 |
| 材質 | 柔和手作木質棋盤、圓潤倒角底座；布料、金屬與水晶有不同高光 |
| 光線 | 固定左上主光，柔和右下投影；輪廓高光保留，影子不覆蓋相鄰交叉點 |
| 鏡頭 | 固定接近俯視；立體感由厚邊、材質與投影提供，控制透視壓縮 |
| 棋盤角色 | A 符號底座先強化體積；B 大人物卡保留表情。普通士兵仍黑白圓子 |
| 資訊 | 主將皇冠、危險、氣與目標提示優先，技能光效只佔局部 |

先做 7×7／390 px 的完整 2.5D 主畫面，再用同一鏡頭和資產檢查 9×9／320 px。角色卡／技能列放棋盤下方。方向是增加角色體積與桌遊手感；不提前換回全身小人物，也不另造陣營版本或重畫全隊。

## 動畫分鏡

`ANIMATION_STORYBOARD.html` 是可離線打開的三職業、四階段分鏡。圖示只畫局部棋盤與動作關係，不是最終人物動作、正式 UI 或完整規則驗證。

| 技能 | 預覽 | 確認後的準備 | 動作重點 | 收尾與持續資訊 |
| --- | --- | --- | --- | --- |
| 戰士築壘 | 英雄旁兩個不同空點，雙目標框 | 盾微傾、底座穩定，90 ms | 兩顆己方普通士兵同時出現，140 ms | 120 ms 落定；保留新白子與氣，不新增防禦建築 |
| 法師魔法之手 | 普通士兵、正交方向、相鄰空點 | 水晶亮一下、小型魔法手勢，80 ms | 被推士兵沿一格路徑滑動，220 ms | 100 ms 光效退去；原位變空、新位置與陣營保留，法師不移動 |
| 盜賊換位 | 相鄰敵方普通士兵與兩個交換點 | 短刃／兜帽瞬間突出，70 ms | 兩条對向短軌跡交換，180 ms | 80 ms 落定；保留兩者身份與新位置，不放大片黑霧 |

提子在上述行動的 Domain 確认結果包含 captures 時才追加 180 ms 局部淡出；純推動被推兵不直接消失。若是合法己方推兵造成其他敵串被提，須分別顯示推動和那些被提的棋子，不把兩種事件混成一個魔法爆炸。

這些節奏總長約 330–400 ms，與比較稿已有的簡單 220 ms 推子不同；尚未實作準備手勢或三職業 sprite。可將關鍵形變集中在開始，尾段快速穩定，避免每次操作都等待長演出。選取保留 160 ms，人物卡 180 ms；無待機循環、相機晃動或全畫面閃光。

## 與規則及素材的接點

正式動作先由成功事件採納最終 snapshot，再以裝飾說明來源和變化；預覽不移動真正棋子、不扣資源。事件失敗時保留原狀。動態途中不能由動畫時間反推落子、推動、交換或提子結果。

魔法之手按照目前 R1：可推雙方普通士兵，曼哈頓 ≤2，正交一格至空點，不推主將／英雄，不連鎖推動，保留歸屬。築壘是英雄四方向相鄰的兩個不同空點各放己方士兵；盜賊換位是與四方向相鄰的敵方普通士兵互換。分鏡不新增傷害、位移範圍或常駐城牆。

保留固定交叉點 anchor、同尺寸底座與陣營輪廓；角色個性在 B 卡片和短技能 cue 中發揮。需要 sprite 時才從核准 reference seed 製作，沿用 anchor／比例與來源紀錄；本輪沒有生成影格。

減少動態使用即時位置替換與靜態方向／結果標記，資訊完全保留。重設／換局面取消過期效果，命中區跟隨已確認狀態，不受裝飾位移影響。目標、氣、皇冠與危險在效果上方；9×9 的約 23 px 圖像仍靠簡化輪廓，而不是加粒子。
