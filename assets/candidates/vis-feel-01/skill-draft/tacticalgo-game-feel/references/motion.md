# 回饋規格起始值

時間是 VIS-FEEL-01 的設計提案，沒有實測效益背書。可依 Owner 審查和實際使用調整。

Owner 指定參考《皇室戰爭》：形體有份量、主道具突出，動作短促且終態清楚；仍維持 TacticalGo 木質桌遊與現有角色風格。動畫設計先給出預覽、準備、主要動作、落定四個 pose／效果關係，不直接生成完整影格集。

| 互動 | 持續資訊 | 可選微動態 | 起始時間 |
| --- | --- | --- | --- |
| 選取英雄 | 選取環、陣營、人物卡 | 棋子 1 → 1.05 → 1；人物卡在自己區塊淡入 | 160 / 180 ms |
| 預覽 | 起點、方向、目的地、可取消 | 靜態標記，不播放成功效果、不扣資源 | 即時 |
| 魔法之手確認 | 原位空點、新位置、方向與結果文字 | 士兵沿正交一格滑動，法師不移動 | 220 ms |
| 成功提子 | 新盤面、移除座標、提子數 | 被提子位置留下不可互動的淡出影像 | 180 ms |
| 減少動態 | 上述全部資訊 | 即時替換，無縮放、位移或粒子 | 即時 |

三技能較完整的候選節奏：築壘盾面準備 90 ms＋兩子同時出現 140 ms＋落定 120 ms；魔法之手手勢 80 ms＋推動 220 ms＋收尾 100 ms；盜賊短刃 cue 70 ms＋對向交換 180 ms＋落定 80 ms。這些尚未製作 sprite，不把常駐城牆、傷害或黑霧當作技能新增規則。

92% 點距的底座最高縮放 1.05 後為 96.6% 點距。交叉點與命中區保持不動；推動只在已確認起終點間滑動。此幾何限制不證明觸控成功率。

圖層由低到高建議為棋盤線、單位、短暫效果、選取／預覽、氣／目標／方向、主將危險。灰階仍靠皇冠、圓／六角底座、菱形、箭頭、加號與驚嘆號區分。

- 預覽與取消只改 UI 暫態。正式整合由 Domain 成功事件及最終 snapshot 更新單位與資源；比較稿的固定 fixture 要標明。靜態／動態共用同一輸入與終態。
- 先採納已確認的結果，再播放裝飾。重設、換局面、切換減少動態及尺寸改變取消舊動態；延遲回呼不覆寫新 snapshot。
- 效果不接收 pointer input。尊重系統 `prefers-reduced-motion`，手動開關也可減少動態，兩者任一啟用即停用裝飾動態。

比較 7×7／390 CSS px 和 9×9／320 CSS px 的初始、預覽、取消、確認、動態中與終態。實測點距和 Token 大小，確認關鍵提示未被遮住。Browser／模擬 touch 只驗證工具；真人、iPhone 與正式遊戲分開記錄。CSS px 不直接等於 iOS pt，約 30 px 點距仍可能誤選。沒有必要增加大套題庫。
