# Cozy Tabletop v0.1

Date: 2026-10-08. Original TacticalGo heroes. Dungeons & Dragons is the requested fantasy party template. The Owner gave positive direction feedback on the generated wooden-board concept and prefers cute physical tabletop miniatures. This does not select exact production masters.

## Rendering locks

Warm dark-brown contours, broad restrained colors, subtle paper/pencil texture, matte soft 2.5D volume, upper-left light and eye catchlight. Large expressive eyes, compact chibi anatomy, nearly frontal gentle three-quarter full-body view. The approximate 2.75-head proportion is a prompt target, not a measured acceptance gate.

| Hero ID | Actual v01 identity | Primary silhouette |
|---|---|---|
| tg-warrior-01 | Chestnut hair, freckles, friendly smile, teal cape, steel shoulders. Shield anatomical LEFT; sword RIGHT. | Broad shield, stable stance |
| tg-mage-01 | Wavy purple bob, plum pointed hat/cloak, cyan crystal staff in anatomical RIGHT hand. | Pointed hat, upright staff |
| tg-rogue-01 | Copper fringe, indigo rounded hood, moss vest, ochre scarf, short blade in anatomical RIGHT hand. | Hood, short blade, ready stance |

All currently share cream cloth and brown leather/boots. Owner's refinement brief asks to reduce this repeated palette: warrior blue-gray/silver/gold; mage purple/blue-violet/cyan; rogue indigo/moss/dark gold. It also prioritizes stronger rogue asymmetry and agility, shield-first warrior defense, and mage control. These changes are planned directions, not already present in v01.

Recommended refinement variants: fortress guardian, classic high-hat seal mage, playful trickster rogue. Preserve friendly expression; avoid dark adult horror. Do not produce all nine suggested variants unless requested.

## Provenance and size limits

Generated PNGs are actually 1254×1254, not the requested 1024. Preserve originals. QA rescales the whole common canvas to 896×896 then pads 64px to 1024; no per-character silhouette fitting or semantic ground-anchor measurement.

48/64px initial visual inspection shows different shield/hat/hood forms. 32px loses face/gear detail; dark background contrast is weaker. No 1-second player test has been run. The rogue's requested deeper skin tone and half-smile were not fully realized; identity revisions must be explicit.

Future board units and avatars must be separately authored if authorized, not silently claimed from portrait reductions. At the v01 checkpoint, next work was layout comparison using existing candidates, with no new hero set or animation. This paragraph records that historical state.

Latest Owner direction (VIS-FEEL-01): use A class-symbol board tokens with B character cards, keep the refined brighter skin tones and single-blade Rogue, default the Mage visual to Magic Hand, and start three-class animation storyboards with Clash Royale as a form/light reference. The v01 PNGs here remain candidate identity/style references, not the latest board tokens or approved production masters. Read the current project checkpoint before choosing which asset version to use.
