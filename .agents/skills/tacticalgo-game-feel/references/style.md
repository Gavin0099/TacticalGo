# TacticalGo 聲畫風格基準

本文件把 Owner 的品質方向轉成可執行的設計約束。材質與節奏建議是 TacticalGo 的設計起點，不是《爐石戰記》的官方參數或已獲接受的最終美術。

## 視覺身份與全畫面

採用溫暖、手工感、可觸摸的奇幻桌遊。人物延續現有 Soft Handmade 2.5D 風格；以材質、光影、比例和清楚的前後層次提升質感。D&D 冒險職業是語彙來源，Hearthstone 是整體完成度標竿，Demeo／Battlemarked 是實體棋盤和微縮場景參考。

| 區域 | 設計方向 | 在遊戲尺寸檢查 |
|---|---|---|
| 棋盤 | 暖木與較平靜的內盤；外框有厚度、接觸陰影、節制的金屬／雕刻細節 | 木紋不穿過文字和棋子輪廓；格線、交叉點與合法標記清楚 |
| 光線 | 延續現有上左方柔光；同一材質有一致高光、陰影與粗糙度 | 不因每張圖各自漂亮而出現互相矛盾的投影 |
| 人物卡 | B 系人物身份、適當留白與明確裁切；邊框形成手持物的厚度感 | 頭臉不被數值遮住；卡片不能擠壓棋盤可操作面積 |
| 棋盤單位 | A Token 的清楚職業符號、穩定 anchor、貼地陰影；可提出保留身份的新呈現候選 | 32／48／64 px 診斷加上真實 runtime 尺寸；不把全身像縮小當作完成 |
| 資訊面板 | 灰青霧面底、暖木外框、古銅與水晶作有限材料族群；用空間和明度分主次 | 回合、AP、能量、氣先於裝飾；同級資訊使用同一間距與字級 |
| 字體 | 標題可有幻想感；繁中說明／數字採清楚字形和足夠行距 | 真實手機尺寸及放大文字；不得靠縮小字體塞入更多裝飾 |
| 操作 | 主要動作有一致的待用、選取、按下、不可用狀態 | 「預覽」與「確認」可分辨；手指不必辨識一像素細線 |

不要把「市場水準」轉成更多金邊、更多粒子或全屏光暈。讓當前操作成為視覺焦點，其他區域安靜地支持棋局。可以改變現有面板樣式；不能把研究圖的桌面比例直接套在直向手機上。

## 角色與顏色

現用素材從當前入口追到 renderer 再確認。v11 棋盤為 `PresentationLab/P02`、牧師 P08，選角三職仍為 asset catalog 的 portrait；不能以 `docs/ios/visual-pack-original-a0.json` 推定整個新對局仍用 A0 renderer。再從 `ios/TacticalGo/Assets.xcassets/` 確認共用 UI 資產，再對照專案角色 skill。v01、B-v02、A Token 是不同表示，不可只看檔名相近就互換。

| 職業 | 現有身份線索 | 特效與聲音設計方向 |
|---|---|---|
| 戰士 | 栗髮、青藍披風、銀色護甲、大盾與劍 | 穩定重心、短促壓實；木／石接觸和節制金屬共鳴；避免把築壘畫成新增永久城牆 |
| 法師 | 紫帽／紫髮、青色水晶法杖 | 聚集、引導、位移、落定；清楚方向與空間；透明氣流／水晶泛音，避免高頻長鳴 |
| 盜賊 | 靛色兜帽、銅色瀏海、苔綠衣、短刃 | 短暫預備和迅速換位；布料／短風切；起終兩個單位都可追蹤，不用黑霧遮去整盤 |
| 牧師 | 現行 P08 金髮、白金服飾與聖典 | 金色／葉形光與柔和收束；目前奉獻只犧牲己兵，不畫補援落子或位移 |

職業色不承擔陣營訊息。黑／白以底座、形狀、文字或標記保持辨識；主將皇冠與危險提示在特效之上。灰階與密集盤面仍能分出主將、英雄、士兵。

對個別人物若已有明確左右裝備、臉型或輪廓要求，鎖定實際 reference；不能用「D&D 風格」重新發明同一人的長相。新動作缺少遮擋面的原始素材時，先說明補畫假設。

## 動畫語法

共用階段為「輸入回饋 → 預備 → 主動作 → 接觸／落定 → 結果回饋 → 安定」。重量由預備、加減速、接觸和小幅回彈建立；不用每個棋子持續浮動來表現活力。

- 預覽保留靜態起點／方向／目的地及可取消狀態；不可提前演成功。
- 位移有明確開始與終點；原位與目的地不能同時畫兩顆正式棋子。被提殘影不可互動。
- 提子與勝負跟隨真實事件；「法師把士兵推走」不自動意味提子，也不能憑特效新增傷害、HP、擊退距離或連鎖。
- 降低動態保持標記、結果文字與同一終態。取消鏡頭震動、快速縮放、大片閃光和非必要位移。
- 預設先使用固定視角。若要鏡頭運動，先證明不影響目標定位、觸控和密集棋局閱讀。

最初可試輸入回饋 80–160 ms、預備 80–180 ms、主要位移 180–350 ms、收尾 100–220 ms；這些只是待比較的 TacticalGo 起始範圍，並非競品量測、既有 runtime 規格或通過門檻。以實測影音調整，保留較短版本作比較。

## 聲音語法

Hearthstone 官方訪談強調回合節奏、施法／命中關鍵拍點與情緒辨識；本專案據此讓每個成功動作有可辨認的聲音輪廓。具體音色仍須實際試聽。

- 每個 cue 有主要作用：操作確認、材質接觸、技能身份、危險或終局。先保留清楚主聲，再加短細節與尾音。
- 輸入音輕、落定音清楚，技能有身份，勝負有較長句子。重要事件發生時讓 BGM／次要聲音讓位，避免所有軌道同時爭搶。
- 相同操作可以有受控變體；保存種子／來源與變體範圍，QA 能重播同一結果。不要讓危險提示在每次 UI 更新重播。
- 正常、專注、危險音樂層保持節奏與相位連續；短暫局面變動不反覆急切換。完整對局檢查重複疲勞。
- 用成品混音檢查峰值、削波、響度、頻譜和循環接縫；單一檔案沒有削波不代表疊音安全。手機喇叭與耳機的可辨性分開驗收。
- 目前程序合成音訊是起點。可提出原創合成、自己錄製或授權聲源的替代；確定需要的素材與授權後才採用，不承諾只調波形參數即可追平競品音色。

## 最小風格比較

同局面呈現正常棋盤、選取／預覽、技能峰值、提子終態和危險局面；必要時加大廳。7×7／9×9、手機直向及實際支援的平板方向分開看。

評語必須指出可見／可聽的差異，例如「青色光圈蓋掉 E3 合法提示」或「落定聲晚於接觸影格」，不要只寫「更高級、更精緻、爐石感」。
