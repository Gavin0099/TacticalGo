# 3D-00｜視角、比例與風格規格

這是未來設計sheet合約，本輪沒有繪製sheet、生成圖片或製作模型。

- 四欄：正面、原画同3/4、側面、背面；後三者未知可見面以「新設計／待核」逐區標示。原画3/4欄才可用直接輪廓/五官比較。
- 共用中性站姿與頭胸像crop、背景、key/fill光、曝光和鏡頭。先為3/4配准選擇一組鏡頭，再固定所有欄；不可宣稱從單張圖推回唯一實體焦距。正交比例sheet與透視原畫配准圖分開，不把同相機原則混成兩者必須同投影。
- 左盾/右劍、手握點、肩甲外輪廓、髮束流向及眉嘴不對稱先鎖定。不得鏡像使慣用手、盾徽或臉的非對稱改變。
- 先頭胸像身份，後才談身體。腿/鞋/背面是新增設計，只有Owner接受後才可進全身；沒有先做骨架/動畫的授權。

## 材質目標

髮束大形與手繪明暗分開處理；金屬肩甲/盾框有分區高光但不刺眼，布料低反光、手套較啞。眼皮/眼角/髮束內部線條應在手機小尺寸存留；輪廓不以巨粗描線蓋掉五官。禁止所有材質共享同一光滑塑膠表面。

手繪色與toon/NPR可作路線，實際可移植性必须在iOS驗證。固定光源比較要包含對比平圖，避免只靠戲劇燈光掩飾形狀差異。

## 兩種顯示契約

選角大卡：臉部、材質與手部接縫可近查；棋盤Token：採現有ground anchor/投影，角色尺寸受格距限制，不靠放大侵入相鄰交點。黑白陣營外側標记與薄底座保持，不遮臉/手/盾徽。64/128頭胸像評閱與實際32/48/64 Token是不同Gate。

尚未指定triangle/texture硬上限，也未測量runtime性能。未來要在目標iPhone/iPad量取同屏7×7/9×9密集局、陰影與描邊開關的幀時間/記憶體/下載大小，之後再定可行預算。
