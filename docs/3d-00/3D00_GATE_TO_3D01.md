# 3D-00｜進 3D-01 前的授權 Gate

| Gate | 本輪證據 / 狀態 | 進下一階段需要 |
|---|---|---|
| G-D00-0 來源 | 512候選實檔、SHA、舊研究只讀索引；1254缺失 | 找回master或Owner明確接受512工作基準；核對素材用途/權利 |
| G-D00-1 身份 | 可見/推定/未知清單已寫；Owner尚未核此表 | 表情、髮束、裝備與不可見區設計核准 |
| G-D00-2 風格 | 大卡/小Token、多視角、材質規格已寫 | 實際各尺寸與iOS外觀候選，不能只靠Blender近景 |
| G-D00-3 路線 | A0及近期2.5D動畫仍採用；B0暫停 | Owner重新選B0，指定手工雕塑/貼圖/runtime負責人 |
| G-D00-4 授權 | 沒有3D-01授權 | 上述均具備且Owner另行授權，才可建立新的頭胸像工程 |

成本引用歷史 `docs/ios/CHARACTER_PRODUCTION_ROUTES.md`：A0約1–3人日、A1約3–7人日、B0頭部約14–25人日。它們是當時的規劃假設，不是本輪實測工時、外包報價或承諾。B0還需分開記角色美術、多視角、材質、工程接線、原生驗證與Owner審查，不能把幾分鐘AI生成時間當全部成本。

2.5D拆層的優點是保留原畫pixels與既有事件；限制是單視角、遮擋補圖、手臂/道具pose範圍。3D能多視角，但身份/表情與runtime渲染風險更高。兩者不是完成度階梯，不因ANIM-01R通過就自動升成3D。

停止條件：唯一身份基準不清、多視角未核、權利未知、不確定技術替代卻先全身/骨架、沿用被否決head-v02或用IoU宣稱身份PASS。未達Gate時保留文件HOLD、繼續A0/2.5D；不開Blender、不新增Mesh/USDZ/App素材。

文件交付可視為DESIGN_READY；角色身份、商用與3D製作授權均Pending。此判斷不影響Gameplay或現有動畫。
