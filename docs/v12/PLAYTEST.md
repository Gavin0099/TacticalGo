# TG12 真人試玩腳本

工程候選不等於好玩，3–8 分鐘是設計假設，不是已量測結果。
招募 3–5 位未參與設計的玩家；先說明基本規則，不提示解法。

1. 開啟「戰術挑戰 → 戰術遠征 · 試玩版」。此章沿用挑戰存取，沒有修改付費帳本。
2. 選「守住補給線」，請玩家自行閱讀與遊玩。主持人不提醒重試、不說兩條解法。
3. 結束後留約 30 秒，觀察是否自行重試、看棋譜、選下一關或離開。
4. 自發選擇完成後才問：「剛才哪一步最難決定？另一種做法會犧牲什麼？」
5. 如離開，記錄玩家原話及原因：不理解／沒壓力／失敗不明／操作／時間／其他。
6. 需要時才讓玩家試下一關；最後由玩家選擇是否匯出本次觀察。

## 匯出解讀

JSON 僅記錄這次開啟的 start/retry/action/hint/pause/resume/result/undo/leave。
activeSeconds 是每次嘗試的前景時間，結算後停止、復原再繼續；重試歸零。
恢復舊存局記 restored-run，不能當成從開局量測的完整局時。
最多 500 事件；滿額後不再新增。無自動上傳，離開章節即丟棄記憶中的觀察。
必須在切換章節或退出前匯出；遊戲進度仍使用獨立本機檔案保存。
result 的完成是局面目標達成，不一定是 Core 捕獲對方主將的對局勝利。
