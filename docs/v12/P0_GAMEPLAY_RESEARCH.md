# P0 正常對局量測：2026-10-23

P0 已取得八場完整正常開局的可重播基線。這批資料支持優先檢查「技能帶來的收益是否值得承受反擊」，尚不能證明好玩、職業平衡或 P1 通過。PR #35 保持 Draft；PR #34、產品規則、Bot 策略、存檔與付費語意未改。

## 方法與範圍

使用正式 `GameSetup.newGame`、`TacticalHints.updatedConfig`、Standard/Baseline Bot，進階技能費用 4、無怪物。四組有順序的配對各跑 7×7 與 9×9：戰士／法師、法師／戰士、盜賊／祭司、祭司／盜賊。每組只有一條確定性路徑，並非全部 16 種配對或真人樣本；勝／和只採 Core 真正終局。

每個「回合」是一方連續使用最多兩個 AP 後才交給對手；不能在兩次行動中間觀察對手回應。保存 8 份現有格式棋譜及 1,058 筆行動前後狀態、有序事件收據，從原始開局獨立重播；完整 GameState（含 superko 歷史）相等。五組原 CI 的有限長度樣本也都與完整棋譜前綴相符。

先前另一輪量測中已完成的 7×7 戰士／法師一局，僅在 30 個產品來源檔案雜湊全部一致後重用；其來源 SHA 與其餘七局分開記載。中斷研究的其他對局不混入本批。

## 等待診斷與 P1 邊界

依預先記載的選樣方式，抽查四職業／兩棋盤各一個連續等待起點，再補三個 7×7 長等待中段，共 11 個自然局面。保留完整歷史，枚舉當前模式合法行動，不合併不同 superko 歷史，檢查對手一次完整反擊。每個局面上限為 60,000 次顯式 apply 或 30 秒；合法行動枚舉的內部工作不計入顯式 apply 數。

- 7 個找到能避免下一次完整反擊立即失去主帥的主動計畫；找到見證即停止，沒有窮舉所有自身走法。
- 1 個（7×7 戰士／法師、零起算 turn 75／ply 76）完整檢查 31 個主動計畫，各有立即敗北的對手回應，只有純等待能避開該次敗北。
- 3 個達到時間限制，結論保留 unknown，不算僵局或沒有好走法。

安全主動計畫可能只是遠處補兵、原地周轉或消耗資源；「不立即輸」不等於比等待更有價值。一輪反擊安全也不等於永久安全或遊戲理論最優。

原有限樣本找到六個同時存在「技能→落兵」「落兵→技能」「落兵→落兵」的合法比較候選，但全域上限六個很早就被戰士／法師填滿，不能宣稱四職業 P1 已涵蓋。另保存 16 個自然局面索引，按各職業／棋盤最早出現的技能連用與有技能可用的普通兩兵回合選取，僅作後續 P1 入口。

P1 尚需比較相同起點下三種順序的收益、對手最佳反制與剩餘資源，特別是祭司進階技能，以及等待局面中的「可走但無收益」與「走了立即輸」。本次不改技能費用、Bot 偏好或終局規則；真人理解、選擇感與再玩意願仍需獨立試玩。

## 量測缺陷與修復

Core 為舊棋譜保留 `MagicHand`，更新版 UI／Bot 在 `expansionSkills && experimentalFriendlyRedeploy` 時會排除它。原研究直接使用 Core 相容行動集，會把更新版法師不能選的舊招算進合法機會與 P1 候選。產品實際 Bot 沒有使用該舊招；缺陷發生在研究量測。

研究測試與獨立觀察器現採相同模式邊界，舊模式保留原招。用原八場棋譜重算觀察資料，沒有重跑或挑選新的 Bot 路徑；八份棋譜位元組與雜湊均不變。回合開始有合法技能的總數由 492 修正為 486，所有勝負、等待、技能實際使用數不變。舊招曾產生一個錯誤的法師安全見證；重新搜尋後即為上述「只有等待安全」局面。

基本技能完整枚舉；進階技能先在 256 個候選內找正向見證，資源足夠卻沒找到時再無上限枚舉確認不存在。進階候選數仍標示為下限，不宣稱完整行動集合大小。原 CI 五局有限樣本仍只作 bounded 診斷，其合法數與完整觀察器的完整缺席檢查不可混用。

大型 JSON 曾被 XCTest stdout／stderr 交錯破壞；現在以 `TG12_RESEARCH_OUTPUT` 直接原子寫檔，CI 保存完整日誌及 JSON。沒有把破損日誌拼接成宣稱有效的資料。
