## 行為合約

戰士沿用 R2：兩個不同空點都在施放前英雄相連己方棋群的邊界；第一顆不延伸第二顆範圍。
法師新增獨立實驗 API 與預設關閉設定。來源必須普通己方士兵、曼哈頓距離英雄 ≤2、且在施放前英雄相連棋群。目的地是該原棋群的空邊界點，不得使用移除來源後新產生的空點，不移主將／英雄／敵兵。一次調度一顆；保留既有一格推動與 R2 異色交換的獨立設定。
共用 1 AP＋2 Mana、每回合最多一次技能。移動不受限制落子的封印影響。先移除來源並放入目的地，再一次結算敵方提子、己方自殺、完整盤面 superko、資源與事件。失敗零事件、零花費、完整 state 不變。

實驗 API 不加入 GameAction、Bot、棋譜或原生入口，避免候選未驗收就進正式對戰。候選移動事件使用既有 PiecePushed（source／destination／identity），不是新增攻擊規則。實验暂無原生復原／存局接線；正式 GameSession 復原保持原測試。
