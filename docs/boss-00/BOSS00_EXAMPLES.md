# BOSS-00｜四份紙上 Expected Trace

這些是推薦方案的**手算規格例子**，沒有新 Boss runtime 或自動平衡測試。座標 A1=左上；x=黑兵、X=黑主將、o=白兵、O=白主將；缺少歷史的情境是 editor 設計例，不聲稱自由對戰歷史可達。AP/Mana 以既有每回合 2 AP、能量上限 6、正常增 1 推演。氣由上下左右空點定義，限制點仍是空氣，不做生命條。

## P2｜製造威脅，誘導對方提前回防

起點 ply3、North 預告，黑有 D1/C2/X:D6，白 O:D2，其他空。
```
...x...
..xO...
.......
.......
.......
...X...
.......
```
O 的兩氣為 D3/E2；射線 D1 已佔、D2 已佔、D3 空。黑、白各 5 Mana。

- 防守路線：黑 C6、E6 加強 X（2→0 AP，白得 2 AP）；白可 E2、F2 擴展。Active 只限制射線的新放棋子，已在 D2 的主將不受傷。黑放棄了迫使白回防的機會。
- 誘導路線：黑 E2 使 O 只剩 D3，再 C6 防守（費用2 AP/0 Mana）。白在限制啟用前 D3 解圍，O 串新增 C3/E3/D4 三氣；再 E3 延伸。下一階段白不能把警告當成「下一秒會死亡」，而是先付出一個救援行動。黑可在射線外施壓；白也可利用新外氣反擊。

這是有可見反制的兩條紙上路線；沒有证明誘導線較強、更好玩或一定成立於真人對局。G-B00-3 待試驗。

| 路線／步驟 | 當前 AP／黑白 Mana | 主將棋群氣／環境 |
|---|---|---|
| 防守：黑 C6 | 黑1 AP；5／5 | X接C6為6氣，O仍2氣；North預告 |
| 防守：黑 E6 | 白2 AP；5／6 | X串8氣，O2氣；白開始回合回復1 |
| 防守：白 E2 | 白1 AP；5／6 | O接E2為4氣 |
| 防守：白 F2 | 黑2 AP；6／6 | O串6氣；Active North，X串8氣 |
| 誘導：黑 E2 | 黑1 AP；5／5 | O剩D3一氣，X4氣；North預告 |
| 誘導：黑 C6 | 白2 AP；5／6 | X接C6為6氣，O1氣 |
| 誘導：白 D3 | 白1 AP；5／6 | O新增C3/E3/D4三氣 |
| 誘導：白 E3 | 黑2 AP；6／6 | O串C3/D4/E4/F3四氣；Active North |

兩條路每手都是成功普通落兵，消耗1 AP/0 Mana、沒有提子/勝負；每個分支各保留 H0 加四個不同盤面，不能把兩條路的 history 混用。Active 禁止的是之後的新落兵，不會刪掉 D3 的白兵或該群現有氣。

## P3｜最後一气不能被環境憑空刪除

起點 ply5、Active North，黑 D1/C2/E2/X:D6；白 O:D2/C6/E6/D7。
```
...x...
..xOx..
.......
.......
.......
..oXo..
...o...
```
O 只剩 D3；X 只剩 D5。雙方6 Mana、黑2 AP。

1. 啟用限制不改棋盤：O/X 均仍1氣；不發提子/勝負，history不增。
2. 黑試D3：受限制，拒絕、AP2/Mana6、仍原盤面。不能把受限空點當「0氣」。
3. 黑D5：普通解圍，X 接到 D5；新增 C5/E5/D4 三氣，AP1/Mana6。
4. 白任何正式獲勝仍需合法玩家 action 的 Core 提子；环境不能獲勝或代替主將死亡。

推薦方案不會同時消失兩主將。若換成推擠可能斬首，這份勝負規格失效，必须停在 OPEN，不沿用此結果。

此例啟用限制與拒絕 D3 均保留 H0。成功 D5 才加入 H1，事件為落兵與1 AP/0 Mana；黑仍當前行動方、黑白Mana6/6，沒有提子/勝負或自動白方 action。

## P4｜碰撞候選與重播/復原邊界

Active East、ply11，黑方法師 H:D4、E4 黑兵、F4 白兵、G4 空，X:D6／O:D2。兩方6 Mana；當前黑2 AP。這是 editor 規格例，不宣稱已有含環境的合法開局重播。

```
.......
...O...
.......
...Hxo.
.......
...X...
.......
```

H/E4棋群5氣，白F4兵3氣，X/O各4氣；受限E4/F4/G4仍按實際佔點及空點計氣。

- 推動到 F4（已佔）按原版魔法之手拒絕 occupied，棋盤/AP/Mana不變。推到G4只有合法一格相鄰來源F4才可，不能為龍息額外推兩格。
- 受限E4/F4/G4不等於碰撞牆；合法既有技能移動到空G4仍可。原子捕獲/自殺/Ko由玩家 action 的Core處理，環境只改落子合法性。
- 保存後進背景：phase、方向East、受限三點、pair counter與Core完整history維持；重開不按時間補發環境。
- 若该玩家 action 剛好讓phase轉Cooldown，undo該journal步同時回復Active與該action前Core history；不得只撤棋子而留下新phase。
- 對照三格推擠：E4→F4有碰撞、F4→G4有位移；G4若變 occupied或盤外，尚無核准的順序。**BLOCK：不能提供唯一 expected board、同時斬首或superko verdict。**這是推擠方案缺口，不是落子限制方案的例外。

需要未來事件/存檔擴充才能驗證重播；本輪只是需求，没有使用動畫或假日志冒充。

| 紙上步驟 | AP／黑白 Mana／phase | Core 與環境預期 |
|---|---|---|
| 試 E4→F4 右推 | 黑2；6/6；Active East | occupied，原子拒絕；H0、盤面不動 |
| F4→G4 右推 | 黑1；4/6；Active East | 來源距法師2、目的地相鄰空點；resourcesSpent(1,2)、piecePushed；無提子/勝負，H1加入 |
| 推動後 | 黑1；4/6；Active East | H/E4串6氣、白G4兵3氣；X/O仍各4氣；技能旗標已用 |
| 黑提前結束 | 白2；4/6；Active East，ply12 | 白開始回合增能量但已在上限；board/history仍H1 |
| 白結束 | 黑2；5/6；Cooldown，ply13 | 完成這對回合，限制清除；沒有推擠、捕獲、勝负，history仍H1 |
| Undo 白結束 | 白2；4/6；Active East，ply12 | 同時復原Core回合/資源與環境phase，不再扣費 |

若G4另被佔，該普通推動也應原子拒絕；若日後採三格環境推擠，這張表沒有提供其合法性豁免或同時死亡決議。

## 文件一致性查核（手算，沒有執行 Boss 程式）

- 下一方開始回合才回復1 Mana，上限6；環境phase不回復/扣費。P1與P2的白方首個回應回合應為6 Mana。
- 沒有任何例子把限制空點視為實體棋子或刪除最後一氣。
- 每次盤面變化各自新增Ko歷史；Pass、環境phase與非法行動不新增盤面歷史。
- 碰撞未定方案保持BLOCK，不用一條選定的臨時演算法填補。
