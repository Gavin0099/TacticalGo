# BOSS-01｜直線清除的候選結算

2026-10-11。Owner 已選：「直接清除線上棋子，另定提子與勝負規則」。**效果已選定；以下細節是供審查的候選設計，未成為正式規則，沒有 Boss 程式或已執行測資。** 1017／1018 自由對戰與挑戰規則維持。

## 建議的最小結算

- 在已預告的三格直線，從同一個 before 棋盤找出雙方所有線上單位，包含士兵、英雄及主將。一次移除這份集合，不依黑白或格點順序逐顆處理。
- 只移除線上的單位，不連帶移除線外相連棋群。龍息屬環境清除，不能偽裝成某玩家的普通提子事件。
- 清除後的空點照常成為氣，不建立永久禁落區。外側棋群依結果盤面查詢氣數；移除本身不額外產生落子，自殺判定仍適用後續普通行動。
- 不額外扣 AP／Mana。被清除的英雄仍維持已召喚紀錄，不因退場重新取得召喚資格。

| 原子清除結果 | 候選勝負 |
|---|---|
| 只移除黑方主將 | 白方獲勝，原因為黑方主將遭龍息清除 |
| 只移除白方主將 | 黑方獲勝，原因為白方主將遭龍息清除 |
| 同時移除雙方主將 | 和局，明記雙主將同時清除 |
| 未移除主將 | 繼續對局 |

若此前玩家 Core 成功行動已判勝或回合上限和局，先尊重該終局，不再追加龍息。新的環境勝負 reason／receipt 必須與普通圍吃主將區分，UI 不能自行判定。

## 歷史、預告與操作

- Ko 候選：強制環境清除不因回到歷史棋形而取消；結果棋形記入歷史，之後玩家行動仍使用既有 positional superko。這是 Boss 模式的明確例外提案，尚未核准或實作；不重設自由對戰 history，不用 UI 跳過 Ko。
- 沿用固定方向及兩方各一完整正常回合的預告窗口作起點，略過首回合 AP 不對稱。清除只在指定已提交的回合邊界發生一次，畫面時鐘／動畫 callback 不觸發結算。
- undo／保存／重播必須包含整個環境狀態、方向、phase、棋盤 history 及同一份清除集合；退出或 App 背景不推進龍息。使用獨立 Boss journal，不遷移或覆寫普通存局。
- 現有 `GameState` 不提供外部直接變更 board 的合法介面；未來需在規則層定義可驗證的原子環境轉移，不能在 SwiftUI 移棋／刪棋冒充 Core 結算。
