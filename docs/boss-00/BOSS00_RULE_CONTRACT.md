## 推薦比較基準：可預告的短期落子限制

紅龍是盤外環境 overlay，視覺中心可對準 D4，但 D4 仍是普通交點。龍不佔點、不加入棋群、不減少氣、不接受召喚或換位目標。無 HP、怒氣資源、擊龍勝利、掉寶或裝備。勝負仍由玩家提掉對手主將決定。

固定方向 North→East→South→West。7×7 的三點射線為 N:D3/D2/D1、E:E4/F4/G4、S:D5/D6/D7、W:C4/B4/A4，不含 D4。全程可見方向、三點與剩餘成對回合，不使用 RNG 或畫面時間。

推薦效果是 active 期間禁止雙方在射線上**落入空點**：普通落兵、召喚、築壘的任一落點都受限制。已存在棋子不動；射線不算實體障礙，因此仍是氣。魔法之手的普通移動與盜賊換位維持原合法性；不得把落子限制偷改成通行障礙。封印與限制相交時採限制聯集，不延長各自期限。非法行動原子拒絕，AP/Mana 不扣。

此效果需未來明確的新 mode 合約，不能直接改 original RuleConfig 或沿用 UI 的 disabled 當規則。本文件提出推薦，沒有 Owner SELECTED。

## 原子與勝負順序

玩家 action → 現行 Core 原子結算與成功收據 → 若已終局就停止環境 → 若回合剛交接且成對回合完結，更新環境 phase → 產生環境狀態收據 → 顯示下一方。

環境限制開始/結束不改 board、Core history、AP、Mana、skillUsed、heroSummoned，不發 piecesCaptured/gameWon。被限制的空點依舊計入 Core liberties。主將只有在玩家合法 action 的正式提子事件中死亡；歸屬維持當前 Core。

推薦方案不產生環境自殺、Ko 重複盤面或同時主將死亡。這些不是通用豁免：若未來改成推擠，所有原子性、同時死亡、自殺、碰撞與 Ko 須另行定案，当前不得製作 runtime。
