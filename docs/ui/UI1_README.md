# UI-1 / UI-1.1：Windows 可操作棋盤（原型）

> 目的：讓 Owner 親手操作 9×9 規則。**UI-1 通過不等於玩法驗證通過**：三職業要到 UI-2 才進入畫面，真正的遊戲性判斷在 PLAY-2。
> 這是 Windows 滑鼠原型，不能取代 iPhone 觸控驗收。

## 執行

```bash
dotnet build TacticalGo.Windows.sln                      # 建置
dotnet run --project src/TacticalGo.Play                  # 直接跑
dotnet publish src/TacticalGo.Play -c Release -r win-x64 --self-contained false -o dist/TacticalGo.Play
```

可執行檔：`dist/TacticalGo.Play/TacticalGo.Play.exe`（framework-dependent，需 .NET 9 Desktop Runtime；`dist/` 不進 git）。

## Slice 3c：第 2 關接到介面（可以實際操作盜賊換位）

> 這是介面接線，**不是玩法驗證**。第 2 關驗證的是「換位能更快獲勝」，不是「換位好玩」；要觀察的是玩家是否理解換位如何改變棋形、是否想在別的局面再用。教學對手不會動，所以仍沒有教攻守取捨。

- **進入第 2 關**：第 1 關最後一段完成後出現「前往第 2 關 ▶」；或「新局／選模式…」選「新手教學：第 2 關」。命令列也可 `TacticalGo.Play.exe --level 2`。
- **放士兵／技能切換**：棋盤下方操作區上排。「放士兵」「技能：換位」二選一（選中的是藍色）；技能不能用時，旁邊一行字說明原因（本回合已用、英雄不在場、沒有合法目標…）。教學裡不顯示 Mana 數字。
- **換位操作**：按「技能：換位」→ 棋盤上盜賊被琥珀色圈起、可選的敵方士兵用薄荷綠虛線圈標出（不用 Hover）→ 點目標 → 棋盤直接畫出**引擎算出的換位結果**（兩點間的箭頭、被提的子淡化加紅色虛線圈、換位後的生存空格數字），說明文字寫明是否會提子／獲勝，但**還沒施放、不消耗行動與能量** → 按「✔ 確定換位」才施放。點別處換目標，「取消」依序清掉目標、再離開技能模式。
- **不合法時**：紅色 ✕ 與簡短原因、側邊欄中文說明、並圈出盜賊位置；沒有任何合法目標時仍可進技能模式點目標看原因。
- **復原／重試**：關卡中新增「復原」（Ctrl+Z 也可，包含對手被動結束回合），「重來本段」不變；段落完成後鎖定，只能「重來本段」或前往下一段／下一關。
- **第 2 關第 2 段**（每回合 2 次行動）：「技能＋放子」與「放子＋技能」兩種順序在這個局面都行得通（已用引擎搜尋驗證），不用技能也能過但要多一回合。
- 版面：操作區改為會自動計算高度的兩排（模式列＋確認列），不會被切掉或遮住棋盤。

## Step 2：第 1 關新手教學（7×7）與「✔ 放這裡」

> 範圍：只教**放子、提子、相連棋子共用生存空格、同一回合可行動兩次**。教學關的對手**不會動**（每回合直接結束回合），所以這一關**沒有教攻守取捨**，也不能據此說新手已理解。工程測試通過也不等於新手看得懂。

- 啟動預設進入教學；「新局／選模式…」可切到自由對局（9×9、兩人輪流，原有功能）。
- 第 1 關三段：
  1. 每回合 1 次行動：提掉被圍住、只剩 1 個生存空格（紅色 1）的白子；提走後原位置留下紅叉。
  2. 每回合 1 次行動：白主將旁邊看起來被圍住，但它與白兵相連共用生存空格（顯示 2）；點白棋會框出整串。把整串圍住才贏。
  3. 每回合 2 次行動：同一回合連下兩子圍死白主將。（若分兩回合完成也算過關，但會提示「可以一回合連下兩子」。）
- 每段完成：棋盤顯示完成橫幅、鎖定落子（仍可點棋子看資訊）、出現「下一段 ▶」或「重來本段」。
- 用字：「還能行動 N 次」取代 AP；沒有職業時不顯示 Mana。
- **確認方式**：操作區固定在棋盤**下方**（大藍色「✔ 放這裡」、「取消」、一行狀態），不蓋住棋盤；棋盤上的泡泡只顯示文字（預覽／原因），並自動避開棋子。
- 對手腳本：`PlayController.OpponentPolicy`，與玩家的行動同屬一個復原步驟；關卡資料在 `Level.cs`，局面是文字圖，由引擎載入（Domain 未改）。

## UI-1.1 新增（理解與操作回饋，不是玩法驗證）

- 常駐目標列：「包圍並提吃對方的『主』就獲勝」。
- 回合標題「第 N 輪・黑／白方回合」，保留引擎 ply 數值（顯示在行動點旁）。
- 雙方主將的**生存空格**即時顯示（取自引擎狀態）：2 個＝橘色提醒，1 個＝紅底警告，棋盤上圈出主將並用紅點標出最後一個生存空格；被提掉＝深色。
- 「生存空格」：點棋子會框出**整個相連棋串**，並說明「相連的棋共用」。
- 點擊的回饋：半透明預覽棋、棋盤上的預覽泡泡、虛線圈出會被提的子（Step 2 起以固定的「✔ 放這裡」按鈕確認）；不能下時顯示紅色 ✕、簡短原因泡泡、圈出相關的子，並在側邊欄用中文說明原因。
- 側邊欄「現在可以做什麼」（提示）與「剛剛發生什麼」（回饋）分開顯示；成功落子會明確回報「✔ 已落子…還有 N AP / 換對手」。
- 沒有職業時隱藏 Mana（UI-2 再啟用）。
- 「怎麼玩？」按鈕：5 頁圖示小教學，每頁是獨立的小棋盤示意，用同一個引擎與同一個棋盤元件產生（不是固定圖片）。

## 操作

| 動作 | 做法 |
|---|---|
| 落子 | 點空交叉點 = **預覽**（半透明棋、會提的子、或非法原因；**不用掉行動**）→ 按下方「✔ 放這裡」（或 Enter）才真的下。點同一點不會落子；點別處只是換預覽位置 |
| 看棋串與生存空格 | 點任何棋子：藍圈 = 整個相連棋串，藍點 = 它們共用的生存空格，訊息列顯示子數與數量 |
| 取消 | 下方「取消」/ Esc |
| 結束回合 / 復原 | 按鈕；Ctrl+Z 復原（可跨回合，還原盤面、AP、Mana、封印、打劫歷史與紀錄） |
| 生存空格數字 | 下拉：隱藏 / 只標危險棋串與主將（預設，2 個橘、1 個紅） / 全部棋串 |
| 新局 | 選規則：先手首回合 1 AP（預設）、2 AP 基線、1 AP 對照 |

不依賴 Hover：非法原因在「選取」後直接顯示於訊息列（紅底），之後移植到 iPhone 同樣成立。

## 架構（為什麼不會有第二套規則）

- `PlayController`：唯一持有正式狀態。合法性 = `ActionValidator.Validate`；預覽與結果 = `GameEngine.Apply`（回傳新狀態，不改舊狀態）；復原 = 還原先前的整個 `GameState`。
- `BoardView`：只畫圖、把點擊轉成棋盤座標。提子預覽圈取自預覽結果的事件，不自己計算。
- `EventText`：把引擎事件翻成中文紀錄。
- Windows 專案與 Domain/Tests 隔離：`TacticalGo.Windows.sln`（Play + Play.Tests + Domain）；`TacticalGo.sln`（Domain、Domain.Tests、Sim）不含任何 Windows-only 專案，可在 Mac/Linux 建置。
