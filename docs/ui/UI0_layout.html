操作

提示（引擎給的文字，UI 不自己判斷）

築壘：請選兩個與戰士相鄰的空點（已選 0 / 2）。
(4,5) 不能放：該點被封印，本回合不能放置。

行動紀錄

  1. 白 封印 (4,5)　[Mana 3→1]
  2. 白 結束回合
  3. 黑 回合開始　AP 2　Mana 4

UI-0 資訊配置要求（驗收清單）

  • 一眼看出：現在輪到誰、剩幾 AP、幾 Mana、每個棋子是士兵／主將／英雄、英雄是哪個職業。
  • 每個棋串的氣數可顯示；1 氣用紅色警示；懸停落點時預覽會提掉哪些子。
  • 選了技能後，合法目標亮綠點、非法但相關的點用紅或紫標示，懸停顯示引擎回傳的原因。
  • 每個行動後，行動紀錄用事件說明發生了什麼（放置、提子、換位、封印到期、換手）。
  • 原型階段職業用文字＋形狀識別（戰／法／盜），不做角色美術。
