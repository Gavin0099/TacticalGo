# EXPANSION-08：职业扩充 Core 合约

L2，2026-10-12工程候选。依据 Owner 本聊天的新英雄/第二技能/魔物目标及十小时自主授权。历史「只做设计」不是此轮完成边界。默认 RuleConfig 不启用，正式1.0规则不变。

## 共同规则

启用 expansionSkills；仅7/9棋盘；进阶耗费1 AP＋4或5 Mana，普通牧师2 Mana。英雄在场、正确职业、当前方、每回合技能未使用是先决条件。英雄技能与魔物能力共享次数。没有额外免费落子、无额外血量或护盾数值。

所有目标以行动前盘面验证；全招同时更新，然后一次敌方提子→己方自杀检查→位置超级Ko→资源/事件/胜负/换手。失败完全保持输入状态和空事件；撤销还原包括历史、召唤、Mana、AP、魔物库存。动画只读成功事件。

## 明确候选

* 牧师「奉献救援」：牺牲曼哈顿距离牧师≤2的一颗己方普通士兵（不是英雄/主将），在行动前己方主将或牧师正邻空点放置一颗己兵。两个位置不同、目的地未被封印。牺牲事件与提子事件分开；总士兵数不增加。主将不移动，牧师召唤3 Mana。意图是移除连接风险，同时远端补主将防线；可以比普通落子更差。
* 战士「战线重整」：从行动前与战士相连棋串选择两颗不同己方普通士兵，搬到行动前该棋串外缘的两个不同空点。目的地距英雄≤4，避免无边界远程兵力调度；移动不受只限制落子的封印影响。不新增士兵，原位置失守。
* 法师「双重牵引」：两颗不同普通士兵，敌我皆可，行动前距法师≤2；各移至正邻一个空点。目的地须行动前为空且互异，不允许利用另一子本招腾出的点或循环交换。两步同时生效，中间棋形不能提子。
* 盜賊「连锁换位」：英雄→正邻敌方普通士兵A→A正邻另一敌方普通士兵B。三个位置互异；英雄到B、A到英雄原点、B到A原点。一次最终结算，不要求中间位置活着。不能选敌主将/英雄；最终英雄被包围则整招拒绝。

## 验证要求

手工审查前后棋形与预期事件，不复制引擎作为期望值。覆盖双职业/两阵营、4与5成本、错误/重复/占用/越界/技能锁/不足Mana、最终自杀/Ko、真实提子与主将胜负、第二AP/最后AP、完全Undo、无中间提子、旧规则Golden回归、旧Records拒收未知候选。另建立合法开局重播，不能只靠人工摆适合技能的局面证明趣味。
