# CONTENT-11：可達局面、反制與候選存局

四職試用與牧師挑戰均從 GameSetup.newGame 逐一通過 GameEngine 重播，不把人工擺盤當作趣味證明。

牧師挑戰：黑方B3:F5棋群（牧師D3），C4唯一一眼；白方A2:G6外環包圍，白主將E2是外環一部分。奉獻E4己兵，在E7補援主將，內部變成C4/E4兩個互不相鄰的真眼。普通填C4自殺，普通E7落子仍只有一眼；白方普通落入任一眼不能提掉另一眼尚存的黑棋群，因此自殺。

法師反制：從上述成功救援繼續實際對局，白法師合法召喚H4；把黑F4向左推到E4，原F4與白G4外環相鄰，不再是安全內眼。黑方若略過回應，白方可填F4再填C4提掉牧師棋群。這不是強制勝利；黑方仍能再次救援或進攻。兩個挑戰分別說明能力的獨特用途與對手的回應，並非宣告平衡通過。

ExpansionMatchRecord專用rulesID與schema1，保存在獨立ExpansionCandidate08/latest.json。只接受標準7/9開局、4/5進階成本、0/1討伐與最多兩種怪物；不保存自訂規則或沒有合法開局記錄的圖層檢查棋形。全部動作重新執行Core並核對最終盤面、雙方Mana、AP、回合、技能鎖、免費討伐窗口、召喚旗標、封印、戰利與解鎖時機、勝負。Superko歷史透過完整逐步重播恢復，不由輸入快照指定。
