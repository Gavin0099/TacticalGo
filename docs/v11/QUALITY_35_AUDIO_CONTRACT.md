# AUDIO-25：英文施法語音節奏

現行1111在所有成功英雄技能排同角色英文台詞。原WAV／英文B身份、主要落定聲與BGM來源保留。新頻率屬呈現狀態，不寫入GameState／棋譜，不改技能費用、合法性或Bot。

先比较兩個可重現候選：A每位角色第一次合格施法可播，之後至少隔兩次合格施法且距上次該角色語音至少12秒；B隔三次施法且至少18秒。任一角色台詞全局至少相隔3秒。合格施法必須是已確認成功英雄技能，且未靜音、語音開啟、音量大於0、時鐘有限；預覽、取消、非法／被拒及靜音不推進次數或消耗首次機會。被時間閘擋住不會排延遲補播，下次成功施法重新判斷。

身份按黑／白玩家與職業區分。新局重置；Undo／背景／中斷只取消舊聲音，不復播，也不重置聽過的語音以免Undo重做反覆念同句。續局為新的暫態呈現session，沒有保存格式遷移。向後／非有限時鐘不播語音，不能損毀後續節奏狀態。

hasVoice必須以本次是否真的排語音決定，靜默施法使用既有無語音SFX gain，不能把原本為語音讓位的低音效音量沿用到靜默技能。缺WAV或排程失敗不得消耗台詞機會（以真實native接受的語音cue為準），維持所有SFX與取消保護。

策略測試使用獨立人工期望的時間／成功序列，含首次、抑制、間隔、双方、開關、時間回退及重置。原生測試核對真實成功receipt和AVAudioPlayer排程，而非只回傳策略布林。與1111等響度比較單次與連續合法技能片段；聲音自然度／手机耳機／疲勞及80–90%目標不是測試數或排程值能證明。

補充：全局3秒指cadence排程判斷間隔，現有聲音起點有.06/.08延遲，不冒稱真機起音精確3秒。重做/快速下一方技能時，視覺已解鎖的前句可繼續完整收尾；若新招因cadence不播語音，保留原句和讓位混音，最末音效/原句尾音共用audio lifetime，不延長AP輸入鎖。Undo/背景/terminal全停。使用兩角色從正常開局可達的連續合法換位→endTurn→調度己兵原生檢查。缺key及AVAudioPlayer返回false是分開失敗路徑，後者未實際誘發；排程接受也不是已聽完整台詞。
