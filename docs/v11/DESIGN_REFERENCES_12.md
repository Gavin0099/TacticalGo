# 1.1設計參考與驗證邊界

目標是職業帶來不同的局面選擇，魔物帶來可放棄的戰略目標；每次技能的原畫動作、物件特效和聲音則讓玩家讀懂已確認結果。以下是參考原則與TacticalGo的自行設計，不是移植其他遊戲的規則。

## 職業

[D&D官方Legacy Cleric介紹](https://www.dndbeyond.com/classes/2-cleric)包含援助、治療和保護隊友，也保留投入戰場的角色性格。這裡只參考職業定位；該頁明示舊版，沒有拿它當最新5.5e規則。TacticalGo沒有HP，因此把援助轉成「犧牲近處士兵，為重要戰線形成新援兵」。不宣稱本遊戲奉獻救援等同D&D Sanctuary法術。

| 職業 | TacticalGo決策 | 實際候選與代價 |
| --- | --- | --- |
| 戰士 | 保留舊線，還是集中兵力？ | 戰線重整轉移原棋群兩兵，不增加子數，舊位會空出。 |
| 法師 | 改變哪兩個連接才有價值？ | 雙重牽引同時位移兩兵，敵我皆可，但兩目的地須在動作前為空。 |
| 盜賊 | 兩段突入後能否活著回應？ | 連鎖換位須有兩顆敵兵作路徑，英雄最後承擔自殺與包圍風險。 |
| 牧師 | 哪個位置可放棄，哪條線不能失去？ | 救援不增子；挑戰用合法開局證明創造兩真眼，也保留法師破眼回應。 |

這些代價來自本遊戲的2 AP、氣與原子結算，不以D&D傷害值或爐石卡牌費用代替平衡測試。Mana4/5與討伐0/1仍是可切換比較，不宣稱定版。

## 聲畫

[Blizzard VFX設計文章](https://hearthstone.blizzard.com/en-us/news/22552047)以讀懂棋盤與職業的顏色、材質、形狀作演出核心，並按事件的重要程度決定規模。對應實作：法師有可辨識魔法手、戰士有盾牌投影、盜賊有換位路徑、牧師有收集與補援的葉片；主將危險標記位於特效上層。此處參考原則，沒有複製官方美術。

[Blizzard聲音團隊訪談](https://news.blizzard.com/en-us/article/23964694/inside-battle-net-meet-the-sound-team-behind-hearthstones-harmonic-design)談固定回合節奏、施法及命中的關鍵拍點，以及聲音的情感和材質。對應實作：衣料/工具準備→位移材質→落定，英文施法聲音先出現，SFX為語音留空間；語音關閉時SFX仍成立。秒數是TacticalGo候選，不是爐石官方規格。

## 魔物

史萊姆代表碰撞與彈開，暗影狼代表路徑与部署，討伐前都阻擋氣。獎勵一次性、下次己方回合解鎖、1 AP/0 Mana，與英雄技能共享每回合一次；沒有永久數值成長。爭奪條件可由兩方提子或位移打破，2:2僵局不自動解鎖。雙怪僅在9×9可選，並非一般對局預設。

## 證据能證明什麼

Core與原生UI證据可證明合法性、資源、原子結算、存局還原及取消。從合法開局可達的四職試用和牧師挑戰避免只靠人工擺盤，動畫檢查仍另用工程棋形並明示其用途。模擬器原生影片保留無聲原檔，混音版是後製參考。

聲音字詞正確、測試通過、PNG透明與SHA一致都不能代替真人演技、美術、樂趣與平衡驗收。真機候選安裝成功也不等於實機聲画錄影或App Store版本完成。
