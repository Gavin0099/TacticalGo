# P28C：討伐提示依選中的動作

已確認點魔物把pending切成huntMonster，但限制／標題仍依技能mode，錯套英雄、Mana、施法次數或0 AP限制。候選只修顯示：討伐以Core對該動作的validate結果為準，顯示魔物名稱、正鄰實際控制數、配置費用、是否獎勵及下一己方回合解鎖。狼須正鄰英雄的拒絕不可說成一般召喚限制；不存在魔物／模式／終局仍由Core拒絕。

技能牌自己的restriction仍依牌的mode，不能因選討伐把原技能誤標可用。取消後恢復技能步驟與quota顯示；錯選／預覽不改資源、棋盤、聲音，確認／Undo仍原子Core。固定44pt標頭、200pt dock、棋盤尺寸不變；標頭可用同一已接受魔物原畫辨識討伐。

以合法開局築壘後的1 AP討伐、0 AP免費窗口、低Mana／已用技能、暗影狼無相鄰英雄與控制不足回歸。正常入口原生測試比較受限技能→合法討伐→取消→確認→Undo，保留失敗及同尺寸圖。不改規則／AI／音檔，討伐和戰利動作先保存現行比較素材再決定是否需新演出；工程成功不等於真人可讀性已驗收。
