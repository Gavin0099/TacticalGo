## 怎麼讀
- 這是「簡單電腦怎麼用各職業」的結果，不是職業強弱。戰士的築壘與牧師的聖所被電腦使用的程度不同，會直接影響勝率。
- 方向性的訊號：**戰士最強、牧師最弱**，與「牧師是否值得選」的疑問同方向，但電腦對電腦的資料不能回答它。
- 還不能說：真人是否也有這個排序、標準難度是否同樣、牧師弱是職業設計還是電腦不會用。要回答需要真人對局與「牧師被怎麼用」的紀錄。
