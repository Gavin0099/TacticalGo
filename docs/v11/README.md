# 魔物戰場 MOB-01～04 試玩入口

本候選在獨立工作樹 codex/v11-monster-battlefield，以本機 origin/main 的 cdab133 為基準。1.0 agent 的工作樹不變；沒有提交、推送或發布。

## 開啟

在這個工作樹開啟 ios/TacticalGo.xcodeproj，選 TacticalGo／Debug，在 Run Arguments 加 `--monster-lab`。正常啟動與 Release 沒有此入口。

選史萊姆／暗影狼、開關戰利能力、0／1 AP、中心／偏中心與雙方職業。變更設定會開新局。可選單怪或「雙怪同場」，本機雙人，沒有 Bot 或正式存局。雙怪固定為 C5 史萊姆、G5 暗影狼，此時種類與位置選項停用。魔物使用依角色風格 skill 繪製的透明候選圖，配上 UI 中立底圈；仍非正式上架素材。

- 點空點後確認落子；英雄操作沿用原三職規則。
- 點怪物預覽討伐，確認才消耗成本／移除；可取消、復原。四鄰友軍至少兩格且多於敵方；暗影狼另需正鄰己方英雄。
- 「載入可達比較局面」重播合法開局，史萊姆 4 個行動／暗影狼 7 個行動，黑方四鄰占 2 格、剩 1 AP。
- 1 AP 可直接討伐並換手；0 AP 討伐後仍剩 1 次普通行動。
- 0 AP 若先花掉最後一次普通行動，仍可免費討伐或略過換手。這個窗口不能再落子／召喚／施法。

## 戰利能力

討伐後歸玩家持有，下一個己方回合才解鎖。畫面公開顯示双方能力與解鎖回合。每份只能用一次，消耗 1 AP／0 能量，與英雄技能共用每回合一次限制；預覽、取消和非法行動都不消耗，復原會還原能力。

| 魔物 | 能力 | 操作 |
|---|---|---|
| 史萊姆 | 黏彈 | 選「戰利能力」，先點己方接觸支點，再點正鄰普通士兵。沿支點→士兵方向推一格，終點要空；士兵敵我皆可 |
| 暗影狼 | 影步 | 選「戰利能力」，點己方英雄同列或同行的一至兩格空點；整條路徑要空，不能穿子 |

「載入能力比較局面」從合法開局討伐、等待解鎖，停在可以使用能力的局面，不是直接注入獎勵。史萊姆先點中央黑子，再點右側黑兵；暗影狼點左側英雄往上兩格的空點。可自行重新落子或讓對手先占目的地，觀察替代選擇。

關閉「戰利能力」可保留原本無獎勵對照。沒有真人試玩資料，兩種討伐成本與能力規則仍是候選；雙怪仍是原型候選。

## 雙怪同場

- 每隻各自占位、各自計算控制；史萊姆仍需至少兩格友軍並占優，暗影狼還需正鄰己方英雄。討伐只移除該隻。
- 能同時持有黏彈與影步，不覆蓋，分別解鎖。選「戰利能力」後用「黏彈／影步」切換；使用只消耗選定能力，仍與英雄技能共用每回合一次，不能兩份連發。
- 「載入可達比較局面」停在第 7 回合黑方 2 AP，兩隻均可討伐。0 AP 重播會先明確略過前面出現的免費窗口；這不代表略過是最佳策略。
- 「載入能力比較局面」從合法開局重播兩次討伐及等待，停在第 11 回合黑方 2 AP，保有兩份已解鎖能力。黏彈點 B6 支點、B5 士兵，向 B4 彈開；影步選 F3，英雄由 F5 沿空路徑移動兩格。兩個選擇都可預覽、取消與復原。
- 0 AP 用完普通行動後，可逐隻討伐；討伐第一隻後另一隻仍可討伐就保留窗口。可中途略過，沒有加送普通行動。
- 同種類重複、第三隻魔物、怪物移動／AI 尚未加入。

## 試玩記錄

每種位置／成本從相同局面比較：直接討伐、先繼續落子再討伐、略過討伐讓對手回應。換邊再玩，勿只觀察先手。

| 比較項 | 記錄 |
|---|---|
| 是否討伐 | 是／否；選擇當時的盤面與行動 |
| 清除怪物的收益 | 哪條棋串增加氣？誰的通道打開？是否也幫到對手？ |
| 替代行動 | 不討伐時最想下哪裡？為何？ |
| 對手回應 | 搶占形成 2:2、提掉控制棋子、或直接進攻主將 |
| 值不值得 | 玩家解釋；不由技能使用率或局部提子數推論 |

無獎勵對照只能驗證占位與清除成本。能力使用／對手堵路的合法重播只證明規則可達與存在反制，不能證明對手會這樣選擇、戰術划算或玩法好玩。真人取捨待辦，不阻擋已授權的後續工程。
