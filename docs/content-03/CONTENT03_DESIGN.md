# CONTENT-03｜邊境攻防設計

三個原版七路挑戰，固定黑方職業、白方普通棋隊。從正式 newGame 經完整合法 source replay 建立，不是任意填盤。未接候選 R3、不新增技能，舊六關保留作入門。成功取決於實際盤面與事件，不匹配答案座標。

## 玩法循環

讀目標 → 選取與只讀預覽 → 確認一次 Core 行動 → 第二 AP 或結束回合 → 白方完整兩次行動 → 根據新棋形完成計畫／失敗 → 復原、重試、下一關。

## 三關與取捨

| 關卡 | 目標 | 已驗證的取捨 |
|---|---|---|
| 守住下一回合 | 經過實際追擊，兩個己方回合內主將與戰士棋群都至少六氣 | 築壘守住 D7 但花兩能量；普通接線让出 D7 但保留能量，兩條路都能成功 |
| 引出回應，再反打 | 第二己方回合結束前提走至少兩敵兵，主將與法師至少三氣 | 先切中央後，敵人會救主將並延伸右串；可以再推左串，也可普通落子夾住右串 |
| 出手，還是留力 | 經敵人回應後提走至少兩敵兵，主將三氣、盜賊存活且兩氣 | 早期換位省兩個行動；普通落子多花一回合但留 Mana。敵方延伸後，再換中央兵已不值得 |

氣數不是生命值：盜賊的兩口局部空點不能被敵人合法填入，不能把兩氣直接說成必死。成功不是「這關一定要用技能」。

全部來源與 12 條成功、錯誤、替代序列，含每步 before/action/events/after、AP/Mana、主將／英雄氣數，在 `artifacts/content-03/solution-and-counterplay-with-config-04.json`，三關分開在 `fixtures-04/`。初始 source 全部由原版 newGame 重播，Ko 留在完整 Core state；對比重播使用 Core 單獨執行，未自行序列化內部 history set。

### 第一關追加的合理失敗救援（05）

原主將 D6 只有 E6、D7 兩個出口。玩家先下 E6、D7，把兩個出口都接到 E7 的戰士與 F7 己兵，主將棋群由兩氣增加為四氣。這是合理的直接救援，但第二個行動只補完連接，沒有向外建立新出口。

對手根據這個實際棋形下 C7、E5，兩個成功的 Core 行動依序把合併棋群的四氣壓成三氣、兩氣，只留下 F6、G7。玩家再沿右下邊界走 F6、G7；F6 雖打開 F5、G6，G7 卻消耗一個出口而沒有增加新出口，結局仍只剩 F5、G6 兩氣。既有救援目標要求六氣，因此顯示「主將棋群只剩 2 氣；反擊後仍未建立足夠的逃生空間。」並鎖定。

這段是實際反制導致的逃生目標失敗，**不是主將立即被提**。Core 此時仍為 ongoing，沒有勝方；第一個直接救援連接會得到至少四氣，不能把敵方兩個行動誇大為能直接提走此棋群。

| 路線 | 第一回合 | 實際敵方反制 | 第二回合 | 結果 |
|---|---|---|---|---|
| 築壘成功 | 築壘 E6、D7 → F6 | 由當前棋形規劃的兩個行動 | F4 → F5 | 完成，保住 D7，花兩能量 |
| 普通落子成功 | E6 → F6 | 由當前棋形規劃的兩個行動 | F4 → F5 | 完成，讓出 D7，保留能量 |
| 看似完成救援的錯誤計畫 | E6 → D7 | C7 → E5，四氣降為兩氣 | F6 → G7 | 兩氣，未完成逃生目標 |

完整三個 source 與原十二條分支都逐欄相同，僅增加 `plausible-rescue-error`，共十三條。新證據為 `artifacts/content-03/solution-and-counterplay-with-rescue-05.json`；重播程式、測試日誌與來源 SHA 位於 `artifacts/content-03/rescue-gap-05/`。04 原件及既有 ZIP 保留。這補足第一關合理救援遭連續反擊的工程證明；真人難度與重玩意願仍須 Owner 判定。

## 反制範圍與難度限制

獨立 AdvancedOpponent 列出全部合法首手，排序保留前 12，再比較完整第二 AP；每回合最多 2000 次明列 Core apply。legalActions 內部工作不包含在這個數量，不能把它當 CPU 時間上限。只代表三個指定場景的決定性反制，不代表一般 AI 升級或最佳反應。

對手按實際棋形產生整回合計畫。首手與次手必須由同一隊列重播，不能無視玩家棋形套固定座標。不同玩家計畫已產生不同實際回應；預算不足只回傳合法 fallback，不聲稱安全。

12 條保存路線不是全部解，有限搜尋不能證明唯一解。工程合法、可解、有反制不等於玩家感到深度，真人難度與重玩意願仍 Pending。提示分級且預設關閉，前三關文案與可選提示直接來自 AdvancedCatalog。
