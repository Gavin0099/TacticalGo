# COMBAT-FEEL-01: 魔法之手可玩演出候選

本輪在 A0 SwiftUI 棋盤加入短演出；原角色 Token、卡片和棋盤素材保持身份。只讀取 Swift Domain 已確認的 `BoardPlayback` 與 `ActionEvent`，不新增 HP、傷害、自由移動或勝負規則。其他行動先保留正式靜態結果；其他技能的完整演出等待 Owner 驗收此片段。

## 中斷邊界

`CombatBoard` 使用 `task(id: playback.id)` 管理播放時鐘；取消、復原、重開或背景切換時上層清除 receipt，舊 task 取消，畫面即讀目前正式盤面。新的 receipt 取代舊 receipt，不排隊補播。只有 `outcome.success == true`、`castMagicHand`、存在 `piecePushed`，且 receipt outcome 等於目前 state 時才啟動此演出。預覽不建立 receipt。

`TimelineView` 由時間取樣，不使用獨立移動棋子狀態，因此 task 取消後不會留下過期棋子；一格滑動期間將來源靜態 Token 排除，避免雙重繪製。提子殘影完全取自事件，包含被提主將與移動後被提士兵。

## 手機閱讀限制與驗收

特效只使用底座細圈與小光點，最大直徑 2.8 個 Token radius，小於一個水平交叉點間距；不使用全屏閃光、遮擋棋盤的粒子或螢幕震動。選取金圈、提子與危險紅圈在最上層，特效不蓋住提示。原始 A0 像素未修改。

實機閱讀仍需 Owner 驗收：在 iPhone 直向 7×7 與 9×9 棋盤，確認上下密集棋子、D3 被提主將和 E4→E3 箭頭仍可辨認。專用示範可使用法師 D4、己方士兵 E4 上推 E3、敵方主將 D3 被提的正式 Domain fixture。驗證音畫與資源結果、滑動中復原／重開、快速確認、非法方向、背景返回、靜音与 Reduced Motion。文件時間表不是實機驗收證據。
