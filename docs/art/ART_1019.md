# 素材分支 `art/hearthstone-materials`：材質與回饋的第一輪（2026-10-19）

目標：以《爐石戰記》的做法（`docs/v11/HEARTHSTONE_GAP_20.md` 的五項差距：材質層次、技能身份、英雄徽章與資源、事件回饋、結算）反覆改善素材。
**範圍與誠實的邊界**：我沒有圖像生成工具，所以不能重畫角色插圖；這一輪改的是用程式畫出來的東西（材質、光影、棋子造型、HUD、特效、橫幅）。角色圖、技能圖示（點陣）、音效都沒有動。沒有任何一項宣稱「達到爐石品質」，每項只標「改善／持平／退步／未檢查」，依據是同一台模擬器、同一局面的前後截圖（`artifacts/art-1019/`）。

只影響 Beta／DEBUG（`#if DEBUG || TACTICALGO_V11`）；Release 以替身型別維持原樣，已確認 Debug、Release、Beta 三種設定都能編譯。DEBUG 加 `--art-v1` 可切回舊畫面逐張比對。沒有碰規則、電腦、存檔、音訊、手勢與無障礙。

## 還沒做、也不能說
- **角色與技能圖的品質差距沒動**：爐石的主要觀感來自手繪插圖與逐格動畫，這一輪碰不到。若要追，需要美術來源（A1 拆層動畫約 3–7 人日是專案文件的規劃假設，不是報價）。
- 沒有在實機上看過；動畫效能（每格重畫的 Canvas、特效）只做了「靜態層快取」這一項保護，沒有量過 FPS。
- 沒有請真人評分。所有判定是我看截圖做的，主觀。
- 小螢幕（iPhone SE）與 iPad 還沒逐張檢查。
- 音效沒有動。

## 怎麼重現
```sh
xcodebuild build -project ios/TacticalGo.xcodeproj -scheme TacticalGo -configuration Debug -destination 'platform=iOS Simulator,id=<裝置>' CODE_SIGNING_ALLOWED=NO
# 產物在 ios/Build/Products/Debug-iphonesimulator/TacticalGo.app
xcrun simctl launch <裝置> com.tacticalgo.prototype --integrated-shell --undo-fixture capture            # 對局畫面
xcrun simctl launch <裝置> com.tacticalgo.prototype --integrated-shell --art-impact capture 0.74         # 凍結的提子畫格（win＝提走主將）
xcrun simctl launch <裝置> com.tacticalgo.prototype --integrated-shell --art-v1 --undo-fixture capture   # 舊畫面
```
