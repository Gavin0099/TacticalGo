# BOT-P2｜1011 有限破局研究計畫與停止點

問題是電腦是否錯過安全而有價值的多回合計畫，不能把所有Pass視作錯誤。承接PR#5完整重播與診斷，保持Core與正式自由對戰預設不变。

本輪先重播40／55，保留40的敵方斬首反例，再測單一可關閉候選。候選只檢查最多一個具有直接壓力或英雄行動的完整回合假說；需要對**所有完整敵方回合**有下一己方回合實際Core獲勝見證，才改變baseline。未完成、預算不足或取消均不能宣稱安全。原本6000明列apply預算涵蓋baseline與研究，Core合法列舉內部工作另計，沒有偷偷改棋規。

驗證依序為：9項離線反例／既有診斷、4項候選預算與取消測試、正式可達負向控制、兩固定測資交錯Release量測、三組六場從開局完整重播。每一步允許HOLD；沒有為了完成Gate硬禁Pass。

現在的停止點：真實40、55、四個正式可達控制及六場對局均未證明改善。工程機制可測，但改善Gate仍HOLD。安靜的非斬首準備、保存Mana的計畫未被本輪候選涵蓋，不能宣稱它們無價值。下一次長期策略研究需要另定觀測及反制範圍；本窗口不繼續擴搜尋，也不把候選接成預設Bot。
