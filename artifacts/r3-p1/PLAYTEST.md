# iPad R3-P1 試玩記錄（真人 0／5）

工程通過與真人體驗分開記錄。此表目前均待 Owner，沒有預填「好玩／平衡」。

| 檢查 | 試玩方式 | 完成證據 | Owner 狀態 |
|---|---|---|---|
| 1. 原局與副本一致 | 續玩原局，截記盤面／回合／AP／能量／主將和英雄身分，右上複製候選；再核對一次 | 兩份對局 ID 與相同起始資訊，原局仍可續玩 | 待試玩 |
| 2. 戰士有取捨 | 記一次值得築壘、一次有合法落點卻選普通落子的原因 | 落點、提子、己群氣、能量與剩餘 AP；對手能否反制 | 待試玩 |
| 3. 法師有取捨 | 分別觀察救援／撤退／反攻；確認是調度而非一格推動 | 原位置／目的地、棋群變化、放棄哪個空間；是否太容易脫困或提子難預測 | 待試玩 |
| 4. 完整對局 | 從開局玩到勝負／和局；保留原版與候選對照棋譜 | 後期技能是否仍重要、AI 純跳過連續多久、盜賊是否有位置價值 | 待試玩 |
| 5. 存檔與操作安全 | 不合法目標、取消、確認、復原，重啟後續玩原版及候選 | 無誤扣資源／盤面異常，原局沒有被覆寫；合法位置與提子預覽可理解 | 待試玩 |

一局結束後先回覆三件事即可：

1. 哪次技能最想再用？如果只有普通落子，少了什麼選擇？
2. 哪次技能不該使用／結果與預期不同？保留該步棋譜。
3. AI 有沒有連續跳過？當時你是否還有值得做的行動？

最後判斷：「拿掉這兩個候選技能，會不會明顯變得比較無聊？」若答案仍不清楚，候選維持試驗，不升格正式規則。沒有要求每個局面都必須能施法。
